# Raketspor site verisi

raketspor.com.tr ürün sayfalarındaki **"Kombini Tamamla"** bölümünün veri dosyası.

- `kombin-veri.txt`: her gece `134_kombin_motoru.py` tarafından üretilir ve buraya otomatik gönderilir.
- İçinde **yalnızca ürün numaraları** ve kombin eşleşmeleri vardır (sıkıştırılmış). Müşteri bilgisi, fiyat ya da stok **yoktur**. Fiyat ve stok sayfada Ticimax'tan canlı okunur.
- Bu depo elle düzenlenmez.
